Состояние на 25.11.2026. Прочитать целиком перед любой работой.

## 1. Что это

Интернет-магазин одежды **«ЛУНАРА»** плюс **программа учёта** (склад, продажи, закупки, реализация, статистика)
в одном приложении.

| Что | Адрес |
|---|---|
| Витрина магазина (рабочая) | https://lunaramod.ru (lunaramoda.ru и www переадресуются сюда) |
| Программа учёта (админка) | https://lunaramod.ru/admin |
| Тестовая копия | https://botmi.ru (+ /admin), своя база, закрыта от поисковиков |

Владелец пишет по-русски, присылает скриншоты с телефона и компьютера. Отвечать просто, без жаргона.
Все его запросы — в `SLD/ЗАПРОСЫ.md`.

## 3. Где что лежит на хостинге (Beget, сервер zip4.beget.com, пользователь mahmadgv)

| | Тест botmi.ru | Рабочий lunaramod.ru |
|---|---|---|
| Папка сайта | `~/botmi.ru` | `~/lunara` (ярлык `~/lunaramod.ru → lunara`) |
| Код | `~/botmi.ru/app` | `~/lunara/app` |
| Фото, видео, файлы чата | `~/botmi.ru/uploads` | `~/lunara/uploads` |
| Настройки сервера (пароль БД, ключи) | `~/botmi.ru/sklad.env` | `~/lunara/sklad.env` |
| База MySQL | `mahmadgv_sklad` | `mahmadgv_luna` |
| Node.js | `~/botmi.ru/.node` | `~/lunara/.node` |

- Сайт запускает Passenger: файл `.htaccess` в папке сайта, `public_html` — ярлык на `app/client/dist`.
  Перезапуск: `touch app/server/tmp/restart.txt`.
- Статику (`/assets`, `/uploads`, `/admin/index.html`) nginx отдаёт **напрямую**, заголовки приложения до неё не доходят.
- `sklad.env`:
  - `DATABASE_URL` — пароль в нём закодирован (%XX);
  - `JWT_SECRET`;
  - `UPLOAD_DIR`;
  - `SITE_URL` — адрес сайта, в код его не зашивать;
  - `CANONICAL_HOST` — основной домен, на него переадресуются остальные.
- Терминал хостинга: панель Beget → Терминал → `ssh localhost -p 222` (рабочая среда с Node и MySQL-клиентом).

## 4. Выкладка (как обновляется сайт)

- Сервер в GitHub не ходит. GitHub Actions упаковывает код (`git archive`) и передаёт его по SSH ключом `BEGET_SSH_KEY`.
- На сервере этот ключ может запустить **только** `~/.sklad-deploy.sh`. Скрипт принимает строку «хэш-коммита домен»,
  кладёт архив в `~/.sklad-release.tar.gz` и запускает `deploy/beget.sh` из архива.
- Список разрешённых доменов задаётся в `deploy/setup-autodeploy.sh` (переменная `DOMAINS`).
- `beget.sh` делает по шагам:
  1. Node.js;
  2. код из архива;
  3. `npm ci`;
  4. проверка базы;
  5. `prisma migrate deploy`;
  6. ярлыки и `.htaccess`;
  7. проверка `/api/health`.
- Признак успеха — строка «Готово».
- Сейчас в `sklad`: push в `main` → только botmi.ru; lunaramod.ru — ручной запуск (см. предупреждение в разделе 2).
- Проверка версии: `curl -s -b beget=begetok https://lunaramod.ru/api/health` → `app` (версия), `version` (коммит), `db`.
  Cookie `beget=begetok` нужна, иначе Beget отдаёт заглушку от ботов.

## 5. Как устроен код (по версии 2.10.2 из `sklad`; в 2.15.1 добавлено то, что перечислено в разделе 2)

- **Сервер:** Node 20/22, Express 4, Prisma 6, MySQL/MariaDB.
- **Клиент:** React 18, Vite 6, Tailwind v4, lucide-react, Recharts.
- **Сборка:** витрина и админка — одна сборка Vite с двумя входами (`index.html` → `dist/shop.html`, `admin/index.html`).
  Папка `client/dist` **хранится в репозитории**; CI проверяет, что она свежая.
- `server/src/routes/`:
  - `shop.js` — витрина: каталог, корзина, заказ, вход покупателя, чат, избранное, отзывы;
  - `products.js`, `stock.js`, `sales.js`, `orders.js` — заказы с сайта и настройки магазина;
  - `stats.js`, `admin.js` — резервная копия, демо;
  - `wb.js` — Wildberries.
- `server/src/`:
  - `seo.js` — HTML для поисковиков, robots, sitemap, фид YML;
  - `jobs.js` — фоновые задачи;
  - `backup.js` — дамп базы и фото;
  - `captcha.js` — своя капча «доказательство работы»;
  - `notify.js` — push, Telegram, MAX;
  - `shop/tbank.js` — оплата Т-Банк и СБП;
  - `shop/legal.js` — юридические документы.
- **Товары как на WB:** модель (`ProductGroup`) → карточка на каждый цвет (`parentId = null`, свои фото, артикул
  `10000000+id`) → размеры (`parentId` = карточка; свой штрихкод, остаток и цена; `size`/`sizeRu`).
  У размеров своих фото нет — использовать `util.fillImages()`.
- **Склад:** партии `Batch`/`BatchUse`, себестоимость по FIFO, всё через `util.changeStock()`.
- **Безопасность:**
  - IP клиента — только `util.clientIp()`;
  - расширение загружаемого файла — по типу, не по имени;
  - уведомления Т-Банка — только при настроенном терминале и со сверкой суммы.
- **Темы:**
  - тёмная — переменные под `.dark` в `client/src/index.css`;
  - светлая — `:root:not(.dark)`;
  - для каждого нового `bg-white/NN` нужно правило в `.dark`.
- **PDF** (ценники 58×40, лист подбора, чек) — `client/src/pdf.js`, jsPDF и шрифт DejaVu (`client/public/fonts`).
- **База знаний** для сотрудников:
  - тексты — `client/src/kb/articles.js`, картинки — `client/public/kb`;
  - скриншоты и видео пересоздаются скриптами `scripts/kb-shots.cjs` и `scripts/kb-videos.cjs`, только на демо-копии.
- **Тесты:** `server/test/api.test.js` (`node --test`), 34 теста в версии 2.10.2.

## 6. Локальная работа

```bash
service mariadb start                       # база часто останавливается
cd server && npm ci && npx prisma migrate deploy && node prisma/seed.js
node src/index.js                           # http://localhost:3000 и /admin
mysql -e "DELETE FROM sklad.SmsCode"; npm test   # перед тестами — сбросить лимиты кодов
cd ../client && npm ci && npx vite build    # после правок клиента обязательно
```

Миграции без интерактива:

```bash
npx prisma migrate diff --from-schema-datasource prisma/schema.prisma \
  --to-schema-datamodel prisma/schema.prisma --script > prisma/migrations/<дата>_<имя>/migration.sql
npx prisma migrate deploy
```

## 7. Правила работы (договорённости с владельцем)

1. Цикл каждой правки:
   1. правка;
   2. сборка клиента;
   3. проверка в браузере, в том числе на ширине телефона 375 px и в светлой и тёмной теме;
   4. тесты;
   5. новая версия в `package.json`;
   6. проверка на секреты;
   7. коммит;
   8. push;
   9. дождаться проверок GitHub;
   10. проверить `/api/health`;
   11. короткий отчёт владельцу.
2. Коммиты от имени владельца: `git -c user.email=mahmadali91@gmail.com -c user.name=mahmadali91 commit`, сообщение по-русски.
3. **Никогда** не коммитить и не писать в ответах: токен WB, пароли Т-Банка, почты и SMS, ключи ботов, SSH-ключи, пароли БД.
4. **Не править код прямо на сервере.** Только через репозиторий и выкладку. Именно так появились расхождения из раздела 2.
5. Решения, которые меняют поведение для людей (роли, рассылки, тестовые режимы, удаление данных), — сначала спросить владельца.
6. Дизайн «как на Wildberries» по удобству, но **свои цвета**.
