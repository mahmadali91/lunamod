# Склад и продажи + интернет-магазин

Сервис для учёта товаров, остатков по складам и продаж, со встроенным интернет-магазином.

- **https://lunaramod.ru** — интернет-магазин «ЛУНАРА» (витрина) для покупателей (lunaramoda.ru переадресуется сюда)
- **https://lunaramod.ru/admin** — программа учёта для сотрудников
- **https://botmi.ru** — тестовая копия: push в `main` обновляет только её; рабочий сайт — по команде владельца

## Интернет-магазин

- Каталог с категориями, поиском, сортировкой, скидками; карточка товара с фото и характеристиками; корзина.
- Вход и регистрация покупателей по email: код приходит письмом (SMTP настраивается в админке). Телефон вводится при оформлении заказа. Защита: повтор кода не чаще раза в минуту, не более 5 кодов в час на адрес и 20 на IP, 5 попыток ввода, код действует 5 минут.
- Получение: самовывоз или курьер (стоимость и порог бесплатной доставки — в настройках).
- Оплата: при получении или онлайн через Т-Банк (интернет-эквайринг API v2: Init, уведомления с проверкой подписи, GetState, Cancel для возврата; чек 54-ФЗ по желанию). Сертификат НУЦ Минцифры для соединения с банком — `server/certs/`.
- Личный кабинет: мои заказы, статус оплаты, повторная оплата, отмена нового заказа.
- В учёте: раздел «Заказы» (статусы, контакты, отметка оплаты, отмена с возвратом денег); «Выдан покупателю» создаёт продажу в канале «Интернет-магазин» и списывает остаток.
- Настройки — раздел «Интернет-магазин»: витрина, склад, доставка, ключи Т-Банка (с проверкой), почта для входа и рассылок. Товар можно скрыть из магазина флажком в карточке.
- **Главная страница — каталог.** Документы: политика конфиденциальности, согласие на обработку ПД (отдельный документ, галочка перед входом), оферта, условия возврата, пользовательское соглашение, реквизиты — шаблоны с подстановкой реквизитов, редактируются в админке. Галочка согласия с офертой при заказе.
- **Доставка**: самовывоз, курьер, Почта России (расчёт по тарификатору tariff.pochta.ru), СДЭК — пункт выдачи и курьер (API v2: города, пункты, тариф; тестовая среда без договора), ПЭК, Авито, Ozon, 5Post (фиксированный тариф до подключения API). Для каждого способа: наценка в % и в ₽, бесплатно от суммы, срок, подсказка. Цена всегда пересчитывается на сервере.
- **Чат на сайте** (только для вошедших покупателей — история хранится в аккаунте): текст, фото и голосовые до 60 с; антиспам — пауза 10 с после сообщения, 15 с при частых сообщениях; в админке «Чаты» — ответы с фото (можно вставить скриншот Ctrl+V), рядом заказы покупателя. Защита от спама, фото только растровые (без SVG).
- **Уведомления** о новых заказах и сообщениях: Web Push в браузер/на телефон (кнопка «Включить уведомления»; на iPhone — после «На экран Домой») , боты MAX и Telegram (кнопки «Найти мой ID», «Проверить», журнал отправки). С российских серверов Telegram часто недоступен — для него можно указать свой прокси-адрес API. Покупателю — пуш об ответе в чате.
- **SEO**: каждую страницу витрины формирует сервер (`server/src/seo.js`) — title, description, canonical, Open Graph, Schema.org (Product, Offer, BreadcrumbList, Organization, WebSite), текст для роботов; `robots.txt`, `sitemap.xml` с картинками; служебные страницы — noindex, несуществующие — 404. Витрина собирается в `dist/shop.html`, чтобы веб-сервер не отдавал её в обход сервера.
- **Яндекс Метрика** — номер счётчика в настройках; ставится только в магазин (не в админку), учитывает переходы внутри сайта и электронную коммерцию. Коды подтверждения Яндекс Вебмастера и Google.
- **Соцсети** (Telegram, ВК, MAX, Instagram*, WhatsApp) — иконки в шапке и подвале.
- **Тёмная тема** в магазине и админке: светлая / тёмная / как в системе.
- **Тестовый режим оплаты**: онлайн-оплата без ключей банка проходит «понарошку». Перед запуском подключите Т-Банк.

- **Карточки «как на WB»** (v2.4): модель (объединённая карточка, до 30 цветов) → карточка на каждый цвет со своим артикулом продавца, фото, видео и описанием → размеры внутри карточки, у каждого свой штрихкод, остаток, цена и этикетка. «Дублировать» — новая карточка другого цвета с теми же размерами; «Из своей карточки» — объединить существующие. На сайте цвета модели показываются фото-миниатюрами. Импорт из Excel: артикул + цвет + размер (тот же артикул другого цвета — новая карточка модели). Продажи по размерам — в карточке товара и в статистике (разрезы «Модели», «Размеры», «Цвета»).
- **Партии и себестоимость**: каждый приход — партия со своей закупочной ценой и поставщиком; продажа списывает FIFO, себестоимость продажи — по фактическим партиям, возврат — в ту же партию, перемещение переносит партии; продажа «в минус» гасится следующим приходом. В карточке товара — история партий и средняя себестоимость остатка.
- **Витрина**: фильтры (размер, цвет, бренд, цена, наличие, скидки), «Новинки» и «Хиты», избранное (в аккаунте), таблицы размеров, параметры модели, галерея со свайпом и зумом, видео, фото по цвету, «Сообщить о поступлении», отзывы с фото и оценкой посадки (модерация в «Отзывах»), «С этим носят», «С этим покупают», «Вы недавно смотрели», напоминание о брошенной корзине, оплата через СБП (QR Т-Банка), установка как приложение (PWA), YML-фид `/feed.yml` для Яндекс Товаров и VK, адреса товаров `/product/12-nazvanie`.

- **Wildberries** (v2.5): раздел «Wildberries» в админке — токен API (хранится только на сервере), загрузка карточек из кабинета: модели (imtID) → карточки цветов (nmID, артикул продавца) → размеры (размер продавца, рос. размер, баркоды WB), цены со скидкой, характеристики, габариты, фото (скачиваются на сервер) и видео (поток HLS). Повторная загрузка обновляет карточки, остатки и закупочные цены не трогает. Карточка товара в админке — в раскладке кабинета WB (варианты · фото · поля), страница товара на сайте — в стиле WB.

## Возможности

- **Товары**: фото (несколько, выбор главного), характеристики (размер, цвет и любые свои), категории, цены (продажа, старая, закупочная), минимальный остаток.
- **Штрихкоды**: каждому товару автоматически выдаётся уникальный EAN-13 (внутренний префикс `200`). Можно ввести свой штрихкод или добавить несколько (например, заводской). Повторы запрещены.
- **Поиск по штрихкоду и артикулу**: строка поиска в шапке, поиск в списке товаров, в кассе, в приходе. USB-сканер работает как клавиатура: отсканировал → Enter → товар найден. На телефоне — кнопка камеры 📷 в строке поиска: сканирует штрихкоды (EAN-13, Code 128 и др.) и QR-коды (нужен https).
- **Товары списком или плиткой**, увеличение фото по нажатию (с перелистыванием).
- **Категории**: отдельная страница с количеством товаров, переименование, удаление.
- **Выгрузка в Excel и загрузка обратно**: товары (узнаются по ID / штрихкоду / артикулу) и остатки (колонка на каждый склад, предпросмотр изменений).
- **Статистика**: сквозная аналитика по каналам, категориям, товарам, покупателям, складам и способам оплаты (выручка, себестоимость, прибыль, маржа, возвраты; расходы каналов → чистая прибыль, ROMI, цена продажи), динамика по дням/месяцам, ABC-анализ товаров и категорий по выручке/прибыли/количеству, выгрузка в Excel.
- **Импорт товаров из Excel/CSV**: шаблон, предпросмотр, создание и обновление по штрихкоду/артикулу, остатки на выбранный склад, отчёт об ошибках по строкам.
- **Демо-данные** (Настройки, только админ): 20 категорий одежды, 100 товаров с иллюстрациями, продажи за год, реализация — удаляются одной кнопкой.
- **Склады**: любое количество; остатки по каждому складу; приход, инвентаризация (ввод фактического остатка), перемещение между складами, массовое редактирование остатков прямо в таблице, история движений; выгрузка остатков в CSV.
- **Продажи**: касса со сканером и подсказкой самых продаваемых товаров, канал продаж, покупатель, способ оплаты, скидка; продажа при нулевом остатке (остаток уходит в минус); возвраты целиком и частично.
- **Реализация (в долг)**: отметка «Под реализацию» в кассе, срок и предоплата; раздел с должниками, приёмом оплат частями и возвратом непроданного товара.
- **Каналы продаж и контрагенты** (покупатели / поставщики).
- **Ценники и этикетки 58×40 мм** (размер и ориентацию можно менять): шаблоны «Ценник» и «Штрихкод», нужное количество копий, печать на термопринтер прямо из браузера.
- **Дашборд**: периоды «Сегодня» (по часам) / 7 / 30 / 90 дней / год, выручка с динамикой к прошлому периоду, прибыль, средний чек, график по дням, доли каналов, топ товаров, товары, которые заканчиваются, последние продажи.
- Пользователи с ролями «Админ» / «Продавец».

## Версии

Номер версии хранится в корневом `package.json` и показывается внизу меню (например, `v1.1.0`).

## Стек

Node.js 20+ · Express · Prisma (SQLite / PostgreSQL / MySQL) · React · Vite · Tailwind CSS · Recharts · JsBarcode

## Локальный запуск

```bash
npm run install:all
cp server/.env.example server/.env        # и поменяйте JWT_SECRET
cd server && npx prisma migrate deploy && npm run seed   # создаёт admin и печатает пароль
npm run demo                              # (необязательно) демо-данные
cd .. && npm run build && npm start       # http://localhost:3000
```

Режим разработки: `npm run dev:server` и `npm run dev:client` (http://localhost:5173).

**После первого входа смените пароль admin в «Настройках».**

## База знаний

**Справочники → База знаний** — пошаговые инструкции со скриншотами (нужные кнопки обведены и пронумерованы) и видеообзоры. Кнопка **«Справка»** вверху любой страницы открывает статью к этому разделу. Тексты — `client/src/kb/articles.js`.
Картинки и видео пересоздаются на копии с демо-данными (не на рабочей базе): `node scripts/kb-shots.cjs` и `node scripts/kb-videos.cjs` (нужны Playwright, Pillow и ffmpeg — подробности в начале скриптов).

## Резервная копия, перенос, свой сервер

Подробная инструкция — **[docs/DEPLOY.md](docs/DEPLOY.md)**: резервная копия базы и фото (админка → Настройки → «Резервная копия»), установка на новый сайт Beget, на свой VPS (Ubuntu + nginx + pm2) и запуск копии на компьютере.

## Печать этикеток

Откройте «Ценники и этикетки» (или кнопку «Ценник» в карточке товара, или выберите несколько товаров в списке). В окне печати браузера: принтер — ваш термопринтер, размер бумаги — 58×40 мм, поля — «Нет», масштаб — 100%. Если этикетка печатается повёрнутой, нажмите кнопку поворота (40×58).

Ценники можно скачать в PDF: кнопка «PDF» на странице этикеток или «Ценники 58×40, PDF» в разделе «Цены и скидки» (по 1 ценнику на размер или по остатку). Каждая этикетка — отдельная страница нужного размера.

## Цены и скидки

Массовые действия для отмеченных товаров: скидка %, изменение цены на % или ₽, цена продажи, цена до скидки, наценка от себестоимости, закупочная цена. Кнопка «Excel» выгружает цены всех товаров и размеров, после правки файл загружается кнопкой «Загрузить» — изменения подсвечиваются, их нужно проверить и сохранить.

## Лист подбора

В окне заказа — «Лист подбора»: фото, цвет, размер, штрихкод и остаток по складам, отметки «собрано» на экране и PDF для печати (A4).

## Автоматическая проверка и деплой

Репозиторий закрытый: GitHub Actions сам отправляет код на хостинг архивом в SSH-соединении, хостингу доступ к GitHub не нужен.

При каждом изменении в ветке `main` GitHub Actions (`.github/workflows/deploy.yml`):

1. **Проверяет**: поднимает MySQL, применяет миграции, запускает автотесты API (`server/test`) — вход, справочники, товары и штрихкоды, поиск, приход/продажа/возврат, перемещение, фото, дашборд; собирает фронтенд.
2. **Выкладывает** на Beget — только если все проверки прошли.
3. **Проверяет сайты** после выкладки: при push — тестовый botmi.ru (новая версия, `db: ok`); рабочий lunaramod.ru обновляется ручным запуском workflow (**Actions → «Проверка и деплой» → Run workflow → sites=lunaramod.ru**).

Если что-то не так, GitHub присылает письмо, а сайт остаётся на предыдущей версии (при ошибке тестов).

**Одноразовая настройка.** В терминале Beget: `ssh localhost -p 222`, затем
```bash
curl -fsSL https://raw.githubusercontent.com/mahmadali91/sklad/main/deploy/setup-autodeploy.sh | bash
```
и добавьте выведенный ключ в GitHub → Settings → Secrets and variables → Actions → `BEGET_SSH_KEY`.
Ключ ограничен на сервере: им можно только запустить обновление сайта.

Локальный запуск тестов: `cd server && DATABASE_URL=mysql://... ADMIN_PASSWORD=test npm test`.
